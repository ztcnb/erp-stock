# 数据库设计

数据库:`erp_stock`(PostgreSQL 16,UTF8)。共 18 张表,初始化脚本见 [`sql/init.sql`](../sql/init.sql)(先 `DROP TABLE IF EXISTS` 再重建,可重复执行,内含全部种子数据)。

## 设计约定

- 主键统一 `BIGSERIAL`(实体侧 MyBatis-Plus `IdType.AUTO`);
- 金额统一 `NUMERIC(18,2)`,加权平均成本 `NUMERIC(18,4)`(减少累计舍入误差),数量 `NUMERIC(18,2)`;
- 外键全部显式声明;单据明细对单头 `ON DELETE CASCADE`,其余引用不级联(靠约束保护数据完整性);
- 高频查询列建索引(单据状态/时间/往来单位、流水商品/仓库/时间等);
- 时间统一 `TIMESTAMP`,由数据库默认值 `now()` 或应用层写入。

## 表清单

| 表 | 说明 |
| --- | --- |
| sys_user | 系统用户(角色 ADMIN/BUYER/SELLER/STOCKER,BCrypt 密码) |
| product_category | 商品分类(树形,parent_id=0 为根) |
| product | 商品(编码唯一,参考进销价、库存预警线) |
| supplier / customer | 供应商 / 客户(编码唯一) |
| warehouse | 仓库(编码唯一) |
| purchase_order / purchase_order_item | 采购订单单头 / 明细 |
| sale_order / sale_order_item | 销售订单单头 / 明细 |
| stock | 实时库存(仓库+商品唯一,数量+加权平均成本) |
| stock_flow | 库存流水(4 种业务类型,记录变动与结存) |
| stock_taking / stock_taking_item | 盘点单 / 明细 |
| payable / payable_record | 应付账款 / 付款记录 |
| receivable / receivable_record | 应收账款 / 收款记录 |

## 关键表结构

### sys_user 系统用户

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGSERIAL PK | |
| username | VARCHAR(50) UNIQUE | 登录名 |
| password | VARCHAR(100) | BCrypt 密文 |
| real_name | VARCHAR(50) | 姓名 |
| role | VARCHAR(20) | ADMIN 管理员 / BUYER 采购员 / SELLER 销售员 / STOCKER 仓管员 |
| phone | VARCHAR(20) | 手机号 |
| status | SMALLINT | 1 启用 / 0 停用 |
| created_at | TIMESTAMP | |

### product 商品

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGSERIAL PK | |
| code | VARCHAR(30) UNIQUE | 商品编码,如 P0001 |
| name | VARCHAR(100) | 名称 |
| category_id | BIGINT FK→product_category | 分类 |
| unit | VARCHAR(10) | 计量单位 |
| spec | VARCHAR(50) | 规格 |
| purchase_price | NUMERIC(18,2) | 参考进价 |
| sale_price | NUMERIC(18,2) | 参考售价 |
| warn_qty | NUMERIC(18,2) | 库存预警线(总库存低于该值预警,0 不预警) |
| status | SMALLINT | 1 在售 / 0 停售 |

索引:`idx_product_category(category_id)`。

### purchase_order 采购订单(sale_order 结构对称)

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | BIGSERIAL PK | |
| order_no | VARCHAR(30) UNIQUE | PO20260901-0001 |
| supplier_id | BIGINT FK→supplier | 供应商(销售单为 customer_id) |
| warehouse_id | BIGINT FK→warehouse | 出入库仓库 |
| status | VARCHAR(20) | DRAFT / APPROVED / STOCKED(销售为 SHIPPED)/ CANCELED |
| total_qty | NUMERIC(18,2) | 合计数量(服务端重算) |
| total_amount | NUMERIC(18,2) | 合计金额(服务端重算) |
| total_cost | NUMERIC(18,2) | 仅销售单:出库成本合计 |
| gross_profit | NUMERIC(18,2) | 仅销售单:毛利 = 金额 − 成本 |
| created_by | BIGINT FK→sys_user | 制单人 |
| created_at / approved_at / stocked_at(shipped_at) | TIMESTAMP | 各节点时间 |

索引:供应商(客户)、状态、创建时间。

### purchase_order_item 采购明细(sale_order_item 对称)

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| order_id | BIGINT FK ON DELETE CASCADE | 所属单头 |
| product_id | BIGINT FK→product | 商品 |
| qty | NUMERIC(18,2) CHECK(>0) | 数量 |
| price | NUMERIC(18,2) CHECK(>=0) | 单价 |
| amount | NUMERIC(18,2) | 金额 = qty × price |
| cost_price | NUMERIC(18,4) | 仅销售明细:出库时点加权平均成本 |
| cost_amount | NUMERIC(18,2) | 仅销售明细:成本金额 |

### stock 实时库存

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| warehouse_id + product_id | UNIQUE 组合 | 库存维度 |
| qty | NUMERIC(18,2) **CHECK(qty >= 0)** | 现存数量,约束保证不出负 |
| avg_cost | NUMERIC(18,4) | 加权平均单位成本 |
| updated_at | TIMESTAMP | 最近变动时间 |

### stock_flow 库存流水

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| biz_type | VARCHAR(20) | PURCHASE_IN 采购入库 / SALE_OUT 销售出库 / TAKING_GAIN 盘盈 / TAKING_LOSS 盘亏 |
| biz_no | VARCHAR(30) | 来源单据编号(可溯源) |
| qty_change | NUMERIC(18,2) | 变动数量(入库正/出库负) |
| qty_after | NUMERIC(18,2) | 变动后该仓该商品结存 |
| price | NUMERIC(18,4) | 入库为采购价,出库为加权平均成本 |
| amount | NUMERIC(18,2) | 金额 |

**恒等式**:`SUM(qty_change) GROUP BY (warehouse_id, product_id)` 恒等于 `stock.qty`,种子数据与运行时均满足。

索引:商品、仓库、时间。

### stock_taking / stock_taking_item 盘点

- 单头:taking_no 唯一(PD 前缀),status = DRAFT 盘点中 / FINISHED 已完成;
- 明细:book_qty 账面快照、actual_qty 实盘(NULL 表示未盘不调整)、diff_qty = 实盘 − 账面。

### payable / receivable 应付、应收

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| order_no | VARCHAR(30) | 来源采购/销售单号 |
| total_amount | NUMERIC(18,2) | 应付/应收总额 |
| paid_amount / received_amount | NUMERIC(18,2) | 累计已核销 |
| status | VARCHAR(20) | UNPAID(UNRECEIVED)/ PARTIAL / PAID(RECEIVED) |

付款/收款记录表(payable_record / receivable_record)逐笔记录金额、方式、经办人,`CHECK (amount > 0)`。

## 种子数据说明

`sql/init.sql` 内置由业务规则模拟器生成的演示数据,口径完全自洽:

- 4 个账号(admin / buyer01 / seller01 / stocker01,密码均 123456);
- 3 级共 24 个分类、42 种商品、8 家供应商、10 家客户、2 个仓库;
- 近 35 天:37 张采购单(31 张已入库,含草稿/已审核/已作废)、54 张销售单(46 张已出库);
- 315 条库存流水、69 条库存记录 —— 流水汇总与库存严格一致;
- 31 条应付、46 条应收,约半数已结清、四分之一部分核销,均有对应付款/收款记录;
- 1 张已完成盘点单(含盘盈盘亏)+ 1 张进行中盘点单;
- 若干商品总库存低于预警线,保证看板预警表格有数据。
